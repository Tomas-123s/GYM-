# المرحلة 3 — التدريب والقياسات (الأيام 10–12)

**الهدف:** تمكين المدربين من إدارة خطط التدريب وتسجيل تقدم الأعضاء دون فقد التاريخ.

## المهام

### مكتبة التمارين والخطط
- [ ] إنشاء Exercise: الاسم، العضلة المستهدفة، وصف، معدات وتعليمات اختيارية.
- [ ] إنشاء WorkoutPlan مرتبط بعضو ومدرب مع اسم وتاريخ بداية/نهاية وحالة.
- [ ] إنشاء WorkoutDay بترتيب عرض، وWorkoutPlanExercise بتمرين ومجموعات وتكرارات/نطاق وراحة وترتيب وملاحظات.
- [ ] تمكين إنشاء/تعديل الخطة وأيامها وتمارينها كوحدة متماسكة؛ تجنب فقد بيانات عند فشل الحفظ.
- [ ] حفظ تاريخ الخطط السابقة وعرض الحالية والسابقة.
- [ ] حصر وصول Coach بالأعضاء المسندين إليه/المصرح بهم؛ فرضه في الخدمة والـAPI والاستعلامات.
- [ ] إنشاء واجهات الخطط والمكتبة وتفاصيل التمارين حسب الدور.
- [ ] توفير `GET /members/{id}/workout-plans` و`POST /workout-plans` ومسارات المكتبة اللازمة.

### القياسات
- [ ] إنشاء BodyMeasurement كسجل تاريخي مستقل بوزن وطول وقياسات اختيارية وتاريخ ومسجل وملاحظات.
- [ ] التحقق من حدود القيم والوحدات؛ منع الكتابة فوق قياسات سابقة.
- [ ] عرض التاريخ والمقارنة بين القياسات؛ إضافة مخطط تقدم الوزن إن سمح الوقت.
- [ ] تقييد التسجيل والعرض حسب دور المدرب ونطاق العضو.
- [ ] توفير `POST /members/{id}/measurements` ومسار قراءة السجل.

### تحقق مرحلي
- [ ] اختبار خطة بأيام وتمارين متعددة وترتيبها، والتحقق من عدم وجود مرجع لتمرين غير موجود.
- [ ] اختبار حفظ قياسين في تاريخين وعرضهما معًا.
- [ ] اختبارات وصول Coach لعضو مصرح وآخر خارج نطاقه.

## معيار الإنجاز

يمكن عرض وإنشاء خطة متكاملة متعددة الأيام والتمارين، ويمكن حفظ وعرض تاريخ قياسات متعدد دون استبدال سجلات سابقة.

## مراجع BRD

WRK-01..08، MEA-01..06، BR-08..09، AC-07..08.
