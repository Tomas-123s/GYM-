# المرحلة 1 — الأعضاء والخطط والاشتراكات (الأيام 4–6)

**الهدف:** إنجاز دورة العضو والاشتراك، مع حفظ التاريخ وسعر الشراء وقواعد التجديد.

## المهام

### الأعضاء
- [ ] بناء Member entity وmigration بالحقول المطلوبة: كود فريد، الاسم، الهاتف كنص، البريد والبيانات الاختيارية، تاريخ الانضمام، ملاحظات، أرشفة وتواريخ الإنشاء/التحديث.
- [ ] تنفيذ إنشاء وتعديل وعرض ملف العضو، مع منع الحذف الدائم عند وجود تاريخ مالي.
- [ ] تطبيق سياسة موثقة لتفرد الهاتف؛ إضافة بحث بالاسم/الهاتف/الكود، فلاتر اشتراك وترقيم صفحات.
- [ ] استبعاد المؤرشفين من القوائم الافتراضية وإتاحة عرضهم صراحةً.
- [ ] إظهار سجل الاشتراكات والدفعات والحضور والتدريب والقياسات عند توفر وحداتها.
- [ ] تنفيذ endpoints: `GET/POST /members`، `GET/PUT /members/{id}`، `POST /members/{id}/archive`.

### الخطط والاشتراكات
- [ ] إنشاء MembershipPlan مع مدة بالأشهر وسعر decimal ووصف وحالة نشاط.
- [ ] إنشاء Subscription يحفظ PlanId وMemberId وتواريخ الفترة والسعر والخصم والسعر النهائي والحالة ومن أنشأه.
- [ ] وضع سياسة واضحة لاحتساب الأشهر التقويمية ونهاية الاشتراك الشاملة، ومعالجة نهاية الشهر.
- [ ] تنفيذ إنشاء وتجديد الاشتراك: التجديد المبكر يبدأ بعد نهاية الحالي؛ المنتهي يبدأ من تاريخ البدء الجديد.
- [ ] حفظ السعر عند الشراء وعدم تغيير الاشتراكات التاريخية بتعديل سعر الخطة.
- [ ] منع تداخل الاشتراكات النشطة وفق السياسة الافتراضية؛ فصل صلاحية الاشتراك عن حالة دفعه.
- [ ] إتاحة حالات فعال/منتهي/قارب على الانتهاء، مع إلغاء/تعليق من خلال صلاحية مسموحة وتدقيق عند تنفيذها.
- [ ] تنفيذ واجهات الخطط والملف الشخصي للعضو وتدفق الإنشاء/التجديد.
- [ ] بناء endpoints الخطط والاشتراكات و`POST /subscriptions/{id}/renew` وقوائم المنتهي والقريب انتهاءً.

### الأمن والاختبار المرحلي
- [ ] فرض Admin على الكتابة الإدارية، والتحقق من نطاق أعضاء Coach في كل قراءة/تعديل مسموح.
- [ ] اختبارات حساب تواريخ شهري/ربع سنوي، التجديد المبكر وبعد الانتهاء، سعر الشراء الثابت والتداخل.
- [ ] اختبارات صلاحيات وقيود الكود/الهاتف والأرشفة.

## معيار الإنجاز

يستطيع Admin إنشاء عضو وخطة واشتراك وتجديده، وتظهر تواريخه وسعره التاريخي بصورة صحيحة؛ لا يفقد الأرشيف السجلات ولا يمكن إنشاء اشتراك متداخل مبهم.

## مراجع BRD

MEM-01..09، PLAN-01..05، SUB-01..08، BR-05، AC-01 وAC-02، APIs members/plans/subscriptions.
